## Use

You can use the Text visualization in the following ways:

- Add a Text visualization. See Add a visualization to a panel .
- In a panel or visualization, from the context-menu select Edit description . Select when finished editing the description, select to cancel.

You can change the formatting of your text, add hyperlinks, and add images.

## Adjust formatting format

When editing your text box or description, you can adjust the font size (heading levels), color, styling (bold, italics, underline) and alignment of selected text. You can also add bullet and numbered lists.

## Add hyperlinks hyperlinks

To add a hyperlink, highlight the text and select in the menu. You can use hyperlinks to provide further assistance to your project recipients. Hyperlinks can link to external websites, documentation pages, [Workspace projects, panels, or visualizations](/en/docs/analytics-platform/using/cja-workspace/curate-share/shareable-links), and more.

## Add images images

To add an image to your project, select in the menu and specify an image URL in **Image URL** (for example https://www.adobe.com/uploads/2018/06/Adobe.png) and select **Save**.

The image URL must be publicly accessible, begin with https, and be of format .png, .jpeg, .jpg, or .gif. Static and animated images are supported.

Be aware that drag and drop insertion of an image is not supported.
