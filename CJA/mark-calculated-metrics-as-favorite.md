# Mark calculated metrics as favorite

Last update: May 13, 2026
- Topics:
- [Calculated Metrics](#)

CREATED FOR:

- User
- Admin

You can mark a calculated metric as a favorite. To mark calculated metrics as favorite helps you to organize your calculated metric. All users can favor calculated metrics.

To favor or unfavor a calculated metric, in the [Calculated metrics manager](/en/docs/analytics-platform/using/cja-components/cja-calcmetrics/cm-workflow/cm-manager):

- Select to favor, or select to unfavor a calculated metric.

You can filter your list of calculated metric by favorites. Select **Other filters** from the **Filter** panel and select **Favorites**. See [Filter the list of calculated metric](/en/docs/analytics-platform/using/cja-components/cja-calcmetrics/cm-workflow/cm-filter) for more information.
