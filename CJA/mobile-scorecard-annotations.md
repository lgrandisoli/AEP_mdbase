# Mobile scorecard annotations

Last update: May 13, 2026
- Topics:
- [Components](#)

CREATED FOR:

- User

You can display annotations that are created in Analysis Workspace in Mobile scorecards. Annotations in mobile scorecards allow you to share contextual data nuances and insights about your organization and campaigns.

## Display annotations in Mobile scorecards

To surface annotations in mobile scorecards, create the annotation first from Workspace projects or from the components menu.

For information on creating annotations, see [Create annotations](/en/docs/analytics-platform/using/cja-components/annotations/create-annotations). Annotations are turned off in mobile scorecards by default and must be enabled for each scorecard that you want to surface in mobile scorecards.

- Turn on annotations. To turn annotations on, see Turn annotations on or off .
- Create an annotation and make sure it is shared to all your projects. See Create annotations for more information.
- Select Show annotations to display the annotation in Mobile Scorecards. You can optionally confirm that Show annotations is selected in Project > Project info and settings

## View annotations in Mobile scorecards

When annotations are enabled, annotation icons are visible in the Scorecard builder. Annotations appear only on charts and tables in the detailed view. Annotations are not visible from the main tile view of the scorecard.

When annotation icons are visible, you cannot fully view or interact with annotations in the builder canvas. Use **Preview** to view and interact with annotations as they appear in the app.

Annotation colors are selected when the annotation is created in Workspace. Gray annotations indicated the presence of more than one annotation.

## Preview annotations

You can preview annotation using Preview. Select an annotation to open details of the annotation.

If more annotations are available, you see multiple dots (●) appear at the bottom of the annotation. Swipe left or right to switch between annotations.
