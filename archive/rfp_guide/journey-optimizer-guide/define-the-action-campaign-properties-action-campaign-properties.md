# Define the Action campaign properties action-campaign-properties

Last update: May 8, 2026
- Topics:
- [Campaigns](#)

CREATED FOR:

- Beginner
- User

To create an Action campaign and define its properties, follow these steps:

- Browse to the Campaigns menu and select the Action tab.
- Click the Create campaign button and select the Scheduled - Marketing campaign type.
- In the Properties tab, enter a name and a description for your campaign.
- Use the Tags field to assign Adobe Experience Platform Unified Tags to your campaign. This allows you to easily classify them and improve search from the campaigns list. Learn how to work with tags .
- You can limit the access to this campaign based on access labels. To add an access limitation, browse to the Manage access button at the top of this page. Make sure to select only labels you have permission for. Learn more about Object Level Access Control .

## Next steps next

Once your Action campaign is created and configured, you can configure its action. [Learn more](/en/docs/journey-optimizer/using/campaigns/action-campaigns/campaign-action)
