# Create hyperlinks in freeform tables

Last update: June 1, 2026
- Topics:
- [Reports](#)
- [Analysis Workspace](#)

CREATED FOR:

- Beginner
- User

Learn how to create hyperlinks for one or more dimension items, making them clickable within a freeform table in Analysis Workspace. You can create hyperlinks for dimension items that have URL values, custom URLs for dimension items that have non-URL values, or for dynamic custom URLs for multiple dimension items by using variables. For detailed documentation, visit [Create hyperlinks for dimensions in a freeform table](/en/docs/analytics/analyze/analysis-workspace/visualizations/freeform-table/freeform-table-hyperlinks).
