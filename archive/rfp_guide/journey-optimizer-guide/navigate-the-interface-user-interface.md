To access Adobe Journey Optimizer, sign in to [Adobe Experience Cloud](https://experience.adobe.com) with your Adobe ID, then select Journey Optimizer.

NOTE
- Components and capabilities available in your environment depend on your [permissions](/en/docs/journey-optimizer/using/access-control/permissions) and [licensing package](https://helpx.adobe.com/legal/product-descriptions/adobe-journey-optimizer.html#_blank).
- This documentation is updated frequently. Some screenshots may differ slightly from your interface.

## Quick tour quick-tour

The Journey Optimizer interface consists of four main areas:

- **Left navigation** - Access all capabilities and features organized by function
- **Top bar** - Universal search, help, notifications, and settings
- **Home page** - Quick access to recent items and helpful resources
- **Main workspace** - Where you create and manage your content

**Tip:** New users can start from the **Home** page to access recent items and use cases, or use the **Help** icon in the top bar for contextual guidance.

## Top bar features top-bar

### Universal search universal-search

Use the search icon to quickly find journeys, campaigns, assets, and other objects across Journey Optimizer. Type keywords to see relevant results from all areas of the platform. [Learn more about universal search](/en/docs/journey-optimizer/using/get-started/work-efficiently/search-filter-categorize#unified-search).

### Help & support help

Click the **Help** icon to:

- Search help articles and videos
- Access contextual help for the current page
- Contact Adobe support
- Share feedback

Contextual help displays guidance relevant to the screen you are viewing and links directly to the corresponding documentation, so you can get the right information without leaving your workflow.

#### Support ticket guidelines support-ticket-guidelines

When contacting Adobe support, include the following to help expedite root cause analysis and resolution:

- **Environment details** – Sandbox name, organization ID, and product area (e.g., Journeys, Campaigns, Decisioning)
- **Impact level** – Severity of the issue (e.g., production blocked, limited functionality, cosmetic)
- **Replication steps** – Clear, step-by-step instructions to reproduce the issue
- **Logs or screenshots** – Relevant error messages, request IDs, or screenshots that illustrate the problem
- **Relevant IDs** – Journey ID, campaign ID, audience ID, or other object identifiers related to the issue

### Notifications in-product-uc

Enable in-product and email notifications to stay informed about:

- **Alerts** - System failures and performance issues
- **Approvals** - Requests requiring your review
- **New releases** - Product updates and new features

To configure notifications:

- Click your profile icon and select **Preferences**
- Under **Notifications**, find **Journey Optimizer**
- Enable the notification types you want to receive

{align="center" width="60%"}

### Language preferences language

The interface is available in English, French, German, Italian, Spanish, Portuguese (Brazilian), Japanese, Korean, Traditional Chinese, and Simplified Chinese.

To change your language:

- Click **Preferences** in your profile menu
- Select your preferred language
- Optionally select a second language as fallback
- Click **Save**

Keyboard shortcuts and accessibility features are available. [Learn more](/en/docs/journey-optimizer/using/get-started/work-efficiently/accessibility)

## Home page home-page

The home page provides:

- **Recents** - Shortcuts to recently created events, journeys, campaigns, and other objects
- **Use cases** - Pre-built scenarios to help you get started quickly (create test profiles, send birthday messages, etc.)
- **Resources** - Links to documentation, tutorials, and support

### Use cases and quick-start workflows use-cases

Quick-start workflows help you accomplish common tasks:

- **Create test profiles** - Generate test profiles using CSV templates
- **Send birthday messages** - Automatically send birthday emails (coming soon)
- **Onboard new customers** - Welcome series for new customers (coming soon)
- **Send push to imported lists** - Quick push notifications from CSV data (coming soon)

Click **View details** to learn more about each use case, or **Begin** to start.

### Main sections main-sections

**Home** - Your starting point with quick access to recently created items and helpful resources

**Journey Management** - Create and manage customer experiences

- **Campaigns** - Create one-time or scheduled messages to specific audiences. [Get started with campaigns](/en/docs/journey-optimizer/using/campaigns/get-started-with-campaigns)
- **Journeys** - Build multi-step, cross-channel customer experiences. [Create your first journey](/en/docs/journey-optimizer/using/orchestrate-journeys/create-journey/journey-gs)
- **Reports** - Analyze performance with integrated Customer Journey Analytics reporting. [View reporting documentation](/en/docs/journey-optimizer/using/reporting/channel-report/campaign-reporting/campaign-global-report-cja)

**Decision Management** - Manage personalized offers. [Learn about decision management](/en/docs/journey-optimizer/using/decisioning/offer-decisioning/get-started-decision/starting-offer-decisioning)

- **Offers** - Create and manage personalized offers
- **Components** - Set up placements, rules, and tags for offers

**Content Management** - Create and organize content

- **Assets** - Centralized repository for images and media. [Manage assets](/en/docs/journey-optimizer/using/content-management/combine/assets)
- **Content templates** - Reusable message templates for campaigns and journeys. [Create templates](/en/docs/journey-optimizer/using/content-management/content-templates/content-templates)
- **Fragments** - Content blocks that can be used across multiple messages. [Work with fragments](/en/docs/journey-optimizer/using/content-management/fragments/fragments)
- **Landing pages** - Web forms for subscriptions and preferences. [Design landing pages](/en/docs/journey-optimizer/using/content-management/landing-pages/get-started-lp)
- **Use Case Playbooks** - Pre-built workflows for common marketing scenarios. [Explore playbooks](/en/docs/journey-optimizer/using/get-started/essentials/ai-features#playbooks)

**Data Management** - Manage your data foundation. [Learn about schemas and datasets](/en/docs/journey-optimizer/using/data-management/get-started-schemas)

- **Schemas** - Define data structure
- **Datasets** - Store and manage data collections
- **Queries** - Write and execute queries
- **Monitoring** - Track data ingestion

**Connections** - Integrate with other systems

- **Sources** - Ingest data from external systems. [Configure sources](/en/docs/journey-optimizer/using/connect-systems/get-started-sources)
- **Destinations** - Export data to cloud storage. [Set up destinations](/en/docs/journey-optimizer/using/data-management/datasets/export-datasets)

**Customer** - Manage audiences and profiles

- **Audiences** - Create and manage customer segments. [Work with audiences](/en/docs/journey-optimizer/using/audiences-profiles-identities/audiences/about-audiences)
- **Subscription lists** - Manage opt-in lists. [Manage subscriptions](/en/docs/journey-optimizer/using/content-management/landing-pages/subscription-list)
- **Profiles** - View unified customer profiles. [Explore profiles](/en/docs/journey-optimizer/using/audiences-profiles-identities/profiles/get-started-profiles)
- **Identities** - Manage identity resolution. [Learn about identities](/en/docs/journey-optimizer/using/audiences-profiles-identities/get-started-identity)

**Privacy** - Control privacy and compliance. [Privacy overview](/en/docs/journey-optimizer/using/privacy/get-started-privacy)

- **Policies** - Define data governance policies
- **Requests** - Handle privacy requests (GDPR, CCPA)
- **Audit** - Review activity logs. [View audit logs](/en/docs/journey-optimizer/using/privacy/audit-logs)
- **Data Lifecycle** - Configure data retention

**Administration** - Configure system settings. [Access control overview](/en/docs/journey-optimizer/using/access-control/permissions-overview)

- **Configurations** - Set up events, data sources, and actions. [Configure channels](/en/docs/journey-optimizer/using/configuration/get-started-configuration)
- **Business rules** - Control message frequency and journey entry. [Set up business rules](/en/docs/journey-optimizer/using/conflict-prioritization/capping-rules/rule-sets)
- **Alerts** - View and manage system alerts. [Monitor alerts](/en/docs/journey-optimizer/using/monitor/monitor-alerts-errors/alerts)
- **Sandboxes** - Manage environments and copy objects between sandboxes. [Work with sandboxes](/en/docs/journey-optimizer/using/connect-systems/sandbox/sandboxes)
- **Channels** - Configure channel settings and deliverability. [Set up channel configurations](/en/docs/journey-optimizer/using/configuration/channel-surfaces) | [Get started with configuration](/en/docs/journey-optimizer/using/configuration/get-started-configuration)
- **Tags** - Organize and categorize content. [Work with unified tags](/en/docs/journey-optimizer/using/get-started/work-efficiently/search-filter-categorize#tags)
