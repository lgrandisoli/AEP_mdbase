# Create an authenticated streaming connection

Last update: May 23, 2026
- Topics:
- [Data Ingestion](#)

CREATED FOR:

- Developer

Authenticated Data Collection allows Adobe Experience Platform services, such as Real-Time Customer Profile and Identity, to differentiate between records coming from trusted sources and untrusted sources. Clients that want to send Personally Identifiable Information (PII) can do so by sending access tokens as part of the POST request.

To learn how to create an authenticated streaming connection, please read the [HTTP API source API guide](/en/docs/experience-platform/sources/api-tutorials/create/streaming/http).
