# Getting started with the Data Prep API getting-started

Last update: May 13, 2026
- Topics:
- [Data Prep](#)

CREATED FOR:

- Developer

This developer guide provides steps for performing various operations in the Adobe Experience Platform Data Prep API.

Using the developer guide requires a working understanding of the various Adobe Experience Platform services involved in working with Data Prep. Before beginning to work with the Data Prep API, please review the documentation for the following services:

- [Data Prep](/en/docs/experience-platform/data-prep/home): Data Prep allows data engineers to map, transform, and validate data to and from Experience Data Model (XDM).
- [Adobe Experience Platform Data Ingestion](/en/docs/experience-platform/ingestion/home): The methods by which data can be sent to Experience Platform.
- [Experience Data Model (XDM) System](/en/docs/experience-platform/xdm/home): The standardized framework by which Experience Platform organizes customer experience data.

In order to successfully make calls to Data Prep API endpoints, please read the guide on [getting started with Experience Platform APIs](/en/docs/experience-platform/landing/platform-apis/api-guide) to learn about required headers and how to read sample API calls.

## Next steps

To begin making calls using the Data Prep API, select one of the available endpoint guides.
