# Integrate Adobe solutions with Customer Journey Analytics

Last update: May 13, 2026
- Topics:
- [Experience Platform Integration](#)

CREATED FOR:

- User
- Admin

Adobe offers many products and solutions that tap into data hosted on Adobe Experience Platform. You can use these guides to learn about the overarching workflows of getting that data into Analysis Workspace to run advanced reports.

Most workflows involve the following steps:

- Use the desired solution or service to send data to Platform as a dataset.
- [Create a connection](/en/docs/analytics-platform/using/cja-connections/create-connection) in Customer Journey Analytics with the desired Dataset.
- [Create a data view](/en/docs/analytics-platform/using/cja-dataviews/create-dataview) containing the desired dimensions and metrics for use in reporting.
- Run reports in Analysis Workspace based on the dimensions and metrics configured within the data view.

Following is a list of some of the available integrations:

- Adobe Analytics
- Target
- Adobe Advertising
- Journey Optimizer
- Decision Management
- Customer AI
