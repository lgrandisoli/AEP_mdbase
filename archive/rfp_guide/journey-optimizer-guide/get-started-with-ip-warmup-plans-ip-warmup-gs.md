# Get started with IP warmup plans ip-warmup-gs

Last update: May 8, 2026
- Topics:
- [IP Warmup Plans](#)

CREATED FOR:

- Experienced
- Admin

With Journey Optimizer, you can easily perform IP warmup workflows directly from the user interface in a standardized and efficient way that follows the best practices for optimal deliverability. When emails are sent using a new platform, Internet service providers (ISPs) are suspicious of IP addresses that are not recognized. If large volumes of emails are suddenly sent, the ISPs often mark them as spam.

To avoid being marked as spam, you can progressively increase the volume sent using the IP warmup plan feature. This new option in the **Administration** menu allows you to automate volume management and simplifies the warmup process without requiring complex journey configurations.

AVAILABILITY
This capability can only be enabled on production-type sandboxes.
The key steps to implement an IP warmup plan are as follows:

- You first need to create one or more campaigns with the IP warmup option enabled. Learn more
- Create an IP warmup plan in Journey Optimizer and upload the Excel sheet prepared with the help of your deliverability consultant. Learn more
- Select a campaign for each phase of your plan and activate the corresponding runs. Learn more
