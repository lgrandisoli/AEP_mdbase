# Open projects

Last update: May 13, 2026
- Topics:
- [Workspace Basics](#)

CREATED FOR:

- User

You can open a project directly from the [Projects](/en/docs/analytics-platform/using/cja-workspace/build-workspace-project/freeform-overview) page. Look for your project in the list. Use [search](/en/docs/analytics-platform/using/cja-workspace/build-workspace-project/freeform-overview#search) or the [segment panel](/en/docs/analytics-platform/using/cja-workspace/build-workspace-project/freeform-overview#segment-panel) to narrow down the list.

- Select the title of your project to open the project in Analysis Workspace.

You can also open a project while you are working in another project.

- Select **Open** from the **Project** menu. You see a dialog similar to the [Projects](/en/docs/analytics-platform/using/cja-workspace/build-workspace-project/freeform-overview) page. Use [search](/en/docs/analytics-platform/using/cja-workspace/build-workspace-project/freeform-overview#search) or the [segment panel](/en/docs/analytics-platform/using/cja-workspace/build-workspace-project/freeform-overview#segment-panel) to narrow down the list.
- Select the title of your project to open the project in Analysis Workspace.

If you cannot find the project and want to start a new project, select **Create new**.

## Open previous version

To open a previously saved version of a project:

- Select Open previous version from the Project menu.
- Review the list of previous versions available in the Previously saved versions dialog. You can switch between All versions and Only versions with notes . For each version, the list shows a timestamp, the editor and saved notes.
- Select a previous version and click Load . The previous version then loads with a notification. The previous version does not become the current saved version of your project until you click Save . If you navigate away from the loaded version, you see the last saved version when you once more want to open a previous version.

## Incompatible data view

When you open a project, you might see an **Incompatible data view** warning dialog. This dialog explains that certain components within the project are not enabled in the selected data view for one of the panels in the project.

To fix this warning, you can:

- **Change the data view**. Select a proper data view from **Change data view:** . If the selected data view is valid, your project opens in Analysis Workspace.
- **Return to landing page**. Your selected project is not opened and you can select another project.
- **Continue anyway**. Your project opens in Analysis Workspace, but shows errors in some of the visualization and the incompatible data views have an alert before the name of the data view.
