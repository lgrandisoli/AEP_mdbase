# Set message & journey capping rules section-overview

Last update: May 8, 2026
Capping rules are part of [conflict management & prioritization](/en/docs/journey-optimizer/using/conflict-prioritization/gs-conflict-prioritization) — they help ensure customers receive the right amount of communication without feeling overwhelmed. Before applying rules, use the [conflict detection tool](/en/docs/journey-optimizer/using/conflict-prioritization/conflicts) to identify overlapping journeys and campaigns. When multiple communications qualify for the same profile, [priority scores](/en/docs/journey-optimizer/using/conflict-prioritization/priority-scores) determine which message is delivered first.

You can set limits on how often messages are sent (frequency capping), how many journeys a profile can enter (journey capping), and when messages are blocked (quiet hours). Rules are grouped into **rule sets** and applied to campaigns or journeys. For programmatic control from external systems, see the [Capping API](/en/docs/journey-optimizer/using/connect-systems/external-systems/capping).
