# Define global variables in Orchestrated campaigns define-global-variables

Last update: May 8, 2026
- Applies to:
- Campaign Orchestration

- Topics:
- [Campaigns](#)

CREATED FOR:

- Intermediate
- User

**Global variables** are name–value pairs you set on a single Orchestrated campaign and reuse on each run, so you can steer **Test** conditions, the rule builder, and other canvas logic with shared values (for example, a default channel or test email) without pasting the same value into every activity.

This page explains how to define global variables. Once they are available, for details on how to use them in rules and **Test** conditions, see [Use variables in Orchestrated campaigns](/en/docs/journey-optimizer/using/campaigns/orchestrated-campaigns/orchestrated-advanced/variables-orchestrated-campaigns).

To add or edit a global variable to an Orchestrated campaign, follow these steps:

- Open the Orchestrated campaign.
- Click the … icon next to Save , then select Edit variables . {modal="regular"}
- Click Add variable and set the variable’s name and value. To edit an existing variable, click the … button and select Edit . {modal="regular"}

To learn how to use global variables in rules and **Test** conditions once they are defined, see [Use variables in Orchestrated campaigns](/en/docs/journey-optimizer/using/campaigns/orchestrated-campaigns/orchestrated-advanced/variables-orchestrated-campaigns#use).
