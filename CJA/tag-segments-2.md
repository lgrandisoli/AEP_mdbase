# Tag segments

Last update: May 13, 2026
- Topics:
- [Filters](#)
- [Segments](#)

CREATED FOR:

- User

In the [Segment manager](/en/docs/analytics-platform/using/cja-components/segments/seg-manage), you can use tags to organize segments. Administrators can tag all segments. Non administroators can tags only the segments they create or have been shared with them.

To tag one or more segments:

- In the Segment manager , select one or more of the segments you want to tag.
- From the action bar, select Tag .
- In the Tag Segments dialog: (optionally) use to search for and limit the list of tags. Based on the list of tags: select one or more existing tags from the list, or enter a new tag and press ENTER . Repeat to add more than one new tag.
- Select Save to save the tags for the segment. Select Cancel to cancel.

Once saved, the tags are listed in the Tag field for the selected segments in the [Segment builder](/en/docs/analytics-platform/using/cja-components/segments/seg-builder).

## Suggestions

Below are some suggestions to organize tags based on:

- Team : For example, Social Marketing, Mobile Marketing.
- Project : For example, Entry-page analysis.
- Category :. For example, Men, Women, Kids.
- Geography : For example: United States, California.
- Workflow : For example: To be approved, Curated
