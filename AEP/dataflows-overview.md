# Dataflows overview

Last update: May 13, 2026
- Topics:
- [Dataflows](#)

CREATED FOR:

- Developer

In Adobe Experience Platform, data is ingested from a wide variety of sources, analyzed within Experience Platform, and activated to a wide variety of destinations. Experience Platform makes the process of tracking this potentially non-linear flow of data easier by providing transparency with dataflows.

## Using dataflows

Dataflows are a representation of data jobs that move data across Experience Platform. These dataflows are configured across different services, helping move data from source connectors to target datasets, where it is then utilized by Identity Service and Real-Time Customer Profile before ultimately being activated to destinations.

To learn more about using dataflows in source connectors, please read the [sources overview](/en/docs/experience-platform/sources/home).

## Preparing data

Data Prep allows data engineers to map, transform, and validate data to and from Experience Data Model (XDM).

To learn more about preparing data after it’s been ingested, please read the [Data Prep overview](/en/docs/experience-platform/data-prep/home).

## Monitoring dataflows

Monitoring dataflows can be done by using either Experience Platform APIs or the Experience Platform UI. To learn how to monitor dataflows using the API, please read the [monitoring dataflows API tutorial](/en/docs/experience-platform/dataflows/api/monitor). To learn how to monitor dataflows within the Experience Platform UI, please read the tutorials on [monitoring dataflows for sources](/en/docs/experience-platform/dataflows/ui/monitor-sources) and [monitoring dataflows for destinations](/en/docs/experience-platform/dataflows/ui/monitor-destinations).
