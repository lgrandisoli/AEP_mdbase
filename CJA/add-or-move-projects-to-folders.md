# Add or move projects to folders

Last update: May 13, 2026
- Topics:
- [Workspace Basics](#)

CREATED FOR:

- User

You can add or move projects to a folder directly from the [Project list](/en/docs/analytics-platform/using/cja-workspace/build-workspace-project/freeform-overview#project-list).

## Move projects to a folder

NOTE
When an administrator moves a project to the Company Folder, the folder is shared with everyone even if the existing shared privileges are restricted. When an administrator moves a project out of the Company Folder, the existing shared privileges are re-applied.
To move projects to a folder from the [Project list](/en/docs/analytics-platform/using/cja-workspace/build-workspace-project/freeform-overview#project-list):

- Select one or more projects that you want to move to a folder.
- Select Move to from the list of possible actions . The Select Folder dialog is displayed.
- Select a folder name from the Folder drop-down menu. The drop-down menu lets you traverse the folder hierarchy to select a subfolder at any level.
- Select Move . The selected projects are added to the folder.

## Add projects to a folder

To add projects to a folder from the [Project list](/en/docs/analytics-platform/using/cja-workspace/build-workspace-project/freeform-overview#project-list):

- Select the folder that you want to add projects to.
- Select Add Projects from the list of possible actions . The Select Folder dialog is displayed.
- Select one or more projects from the Select projects to add to folder .
- Select Add .

NOTE
Only Admins can add projects to the Company Folder or create a new project and save it to the Company Folder
