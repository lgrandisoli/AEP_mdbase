You can share, filter, tag, approve, copy, share, and delete date ranges and mark date ranges as favorite from a central Date ranges management interface. To manage date ranges:

- Select **Components** in the main interface, then select **Date ranges**.

### Active filter bar

The filter bar ➌ shows the active filters (if any). You can quickly remove a filter using . If more than one filter is specified, use **Remove all** to remove all filters.

### Filter panel

You can filter date ranges using the **Filter** left panel ➍. The filter panel displays the type of filter and the number of date ranges that honor the filter. Select to toggle the display of the filter panel.

To filter the list of filters:

- Select to open the Filters panel. If you need more space for the Filters list, you can select once more to close the panel.
- You can filter the date ranges using any of the available filter sections . note info INFO Items refer to the date range items displayed in the Date ranges list .

## Edit date ranges

You edit a date range in two ways:

- In a Workspace project, use the Component info icon.
- In the Date ranges list , select the title of the date range.

You use the [Date range builder](/en/docs/analytics-platform/using/cja-components/cja-date-ranges/create#date-range-builder) to edit the date range.

Use the date range manager to share, rename, or delete date ranges. To reach the date manager:

- Log in to [analytics.adobe.com](https://analytics.adobe.com) using your AdobeID credentials.
- Navigate to Components > Date Ranges.
