# Use cases section-overview

Last update: May 8, 2026
Adobe Journey Optimizer’s use cases empower you to create meaningful, personalized customer experiences by combining marketing strategies, technical workflows, and real-time triggers. Whether you’re managing opt-outs, designing multi-channel campaigns, or integrating external systems, these use cases provide actionable examples to help you succeed. You’ll find topics ranging from leveraging experience events for dynamic personalization to building journeys that integrate with Adobe Campaign or send messages to subscriber lists. Each use case offers practical steps and insights, making it easy to explore innovative ways to engage your audience and optimize your customer journeys effectively.

## Use Cases

Learn through use cases

Explore practical examples and strategies to maximize Adobe Journey Optimizer capabilities, including experience events, datasets, and marketing workflows.

[Start learning](/en/docs/journey-optimizer/using/orchestrate-journeys/journey-use-cases/jo-use-cases)

Experience event lookup

Use experience event alternatives to manage opt-outs, personalize content, and address common challenges in journey orchestration.

[Learn more](/en/docs/journey-optimizer/using/orchestrate-journeys/journey-use-cases/exp-event-lookup)

Send multi-channel messages

Create journeys that leverage audience segmentation and event triggers to send personalized messages across multiple channels.

[Follow the tutorial](/en/docs/journey-optimizer/using/orchestrate-journeys/journey-use-cases/journeys-uc)

Send a message using Campaign v7/v8

Integrate Adobe Campaign with Journey Optimizer to send email messages using transactional templates and event triggers.

[Get started](/en/docs/journey-optimizer/using/orchestrate-journeys/journey-use-cases/ajo-ac)

Send a message to subscribers

Set up journeys to send messages to subscribers based on preferences and dynamically retrieved data.

[Try the tutorial](/en/docs/journey-optimizer/using/orchestrate-journeys/journey-use-cases/message-to-subscribers-uc)

Pass collections dynamically using custom actions

Learn how to configure custom actions to pass dynamic data collections in journey orchestration.

[Learn more](/en/docs/journey-optimizer/using/orchestrate-journeys/journey-use-cases/collections)

## Additional Resources

- **Limit throughput with external data sources & custom actions** - Optimize journey throughput and manage limits for external systems using Data Sources and Custom Actions.
- **Use custom actions to write journey events in Experience Platform** - Configure authenticated calls and HTTP API endpoints to write journey events into Adobe Experience Platform.
- **Remove profiles from a live journey** - For business or operation reasons, you may need to remove some profiles from a live journey, and exclude profiles matching a specific criteria currently in the journey. This can be performed by pausing the journey.
