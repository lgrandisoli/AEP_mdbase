A **Freeform panel** is a blank panel with a [Freeform table](/en/docs/analytics-platform/using/cja-workspace/visualizations/freeform-table/freeform-table) visualization as the default starting state.

## Use

To use an **Freeform panel**:

- Create an Freeform panel . For information about how to create a panel, see Create a panel .
- See Use components in Workspace how you can add components to the freeform panel and Freeform table visualization.
