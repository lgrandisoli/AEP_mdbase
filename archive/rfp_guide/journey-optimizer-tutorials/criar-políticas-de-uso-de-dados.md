# Criar políticas de uso de dados

Last update: Thu Apr 30 2026 00:00:00 GMT+0000 (Coordinated Universal Time)
- Tópicos:
- [Governança](#)

Criado para:

- Iniciante
- Usuário

Saiba como criar e gerenciar políticas de uso de dados. As políticas de uso de dados permitem restringir o uso de dados para fins específicos com base nos rótulos dos dados. Para saber mais sobre a abordagem baseada em API, consulte [Criar políticas de uso de dados com a API](/pt-br/docs/experience-platform/data-governance/policies/create?lang=pt-BR).

NOTE
O vídeo demonstra esse recurso na interface da Adobe Experience Platform. A mesma funcionalidade está disponível na interface do Journey Optimizer, na seção PRIVACIDADE, na navegação à esquerda.
