# Copy calculated metrics

Last update: May 13, 2026
- Topics:
- [Calculated Metrics](#)

CREATED FOR:

- User
- Admin

When creating a new calculated metric, you do not have to start from scratch. You can copy an existing calculated metric that already provides a proper definition to start from, then modify the version you copied.

To copy a calculated metrics in the [Calculated metrics manager](/en/docs/analytics-platform/using/cja-components/cja-calcmetrics/cm-workflow/cm-manager):

- In the [Calculated metric manager](/en/docs/analytics-platform/using/cja-components/cja-calcmetrics/cm-workflow/cm-manager), select one or more of the calculated metrics you want to copy.
- From the action bar, select **Copy**.

The new calculated metrics are created with the same name and suffix (Copy).
