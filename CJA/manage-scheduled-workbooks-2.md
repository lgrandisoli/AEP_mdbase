# Manage scheduled workbooks

Last update: May 13, 2026
- Topics:
- [Report Builder](#)

CREATED FOR:

- User
- Admin

You can schedule a workbook for sharing through email or by exporting to a cloud destination, as described in the following articles:

- Schedule workbooks by sharing through email
- Schedule workbooks for export to cloud destinations

The following sections describe how to manage workbooks after they are scheduled:

## View and manage scheduled workbooks

You can view and manage all scheduled workbooks in the **Workbooks** tab.

- Select Schedule in the Report Builder hub
- Select the Workbooks tab. You see a list of all scheduled workbooks. (Alternatively, you can select the Legacy tab to view a list of legacy workbooks that need to be migrated to the new Report builder.) {modal="regular"}
- Do any of the following: Hover over the icon to see the status of a scheduled workbook. In the search field , search for specific scheduled workbooks. Select the column icon to define which columns to show. Select the filter icon , then select Show all to show all scheduled workbooks for a given org.
- Select one or more workbooks. {modal="regular"} The following options are available: table 0-row-2 1-row-2 2-row-2 3-row-2 4-row-2 5-row-2 6-row-2 Option Description Edit the schedule for a selected workbook. Show the history of selected workbooks. Pause the schedule of selected workbooks. Resume the schedule of selected workbooks. Download the selected workbook into a new workbook. Delete the schedule of selected workbooks.

## History and status of scheduled workbooks

You can view the history and status of scheduled workbooks in the **History** tab.

- Select Schedule in the Report Builder hub.
- Select the History tab. You see a list of all scheduled workbooks. {modal="regular"} Use to search for specific workbooks in the list. Use to define which columns to show. The History tab allows you to review the status of each scheduled task. A separate row documents the status change for each scheduled task. A indicates that the workbook was sent successfully. A indicates that an error occurred.

Alternatively, you can select for one or more selected workbooks in the **Workbooks** tab. This action shows the **History** tab with a list filtered by your selection. Select to remove a filter.
