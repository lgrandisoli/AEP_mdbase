The **Bullet** visualization shows how a metric compares to, or measures against, performance ranges (goals).

The bullet graph features a single, primary measure (for example, current year-to-date revenue) and allows you to enter qualitative ranges performance ranges (for example, compared to a target revenue). You can specify high, medium, and low goal ranges. You can specify goal ranges in **Settings**.

See [Bullet graph visualization](/en/docs/customer-journey-analytics-learn/tutorials/analysis-workspace/visualizations/add-bullet-graph-visualizations#_blank) for a demo video.
