# Approve segments

Last update: May 13, 2026

- [Segments](#)

CREATED FOR:

- User

In the [Segment manager](/en/docs/analytics-platform/using/cja-components/segments/seg-manage), you can approve and unapprove segments. Only administrators can approve segments.

To approve segments:

- In the [Segment manager](/en/docs/analytics-platform/using/cja-components/segments/seg-manage), select one or more of the segments you want to approve.
- From the action bar, select **Approve**. The approved segments are indicated with

To unapprove segments:

- In the [Segment manager](/en/docs/analytics-platform/using/cja-components/segments/seg-manage), select one or more of the segments you want to unapprove.
- From the action bar, select **Unapprove**.

You can segment your list of segments by approved segments. Select **Other segments** from the **Segment** panel and select **Approved**. See [Filter the list of segments](/en/docs/analytics-platform/using/cja-components/segments/seg-filter) for more information.
