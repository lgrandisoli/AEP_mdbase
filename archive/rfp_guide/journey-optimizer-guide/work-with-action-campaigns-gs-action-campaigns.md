## About Action campaigns about

Action campaigns (or Scheduled campaigns) allow for simple ad-hoc batch communications for marketing use cases like promotional offers, engagement campaigns, announcements, legal notices, or policy updates.

## Key steps for Action campaigns creation steps

Before starting with campaigns, check the following prerequisites listed [in this section](/en/docs/journey-optimizer/using/campaigns/get-started-with-campaigns#prerequisites). Once these prerequisites are met, you can start creating your campaign:

- [Define the Action campaign properties](/en/docs/journey-optimizer/using/campaigns/action-campaigns/campaign-properties)
- [Configure the campaign action](/en/docs/journey-optimizer/using/campaigns/action-campaigns/campaign-action)
- [Edit the Action campaign content](/en/docs/journey-optimizer/using/campaigns/action-campaigns/campaign-content)
- [Define the Action campaign audience](/en/docs/journey-optimizer/using/campaigns/action-campaigns/campaign-audience)
- [Schedule the Action campaign](/en/docs/journey-optimizer/using/campaigns/action-campaigns/campaign-schedule). Optionally, [send using waves](/en/docs/journey-optimizer/using/campaigns/action-campaigns/send-using-waves) to deliver the message in batches over time.
- [Review & activate the Action campaign](/en/docs/journey-optimizer/using/campaigns/action-campaigns/review-activate-campaign)

Learn more about the [complete campaign creation workflow with type-specific guides →](/en/docs/journey-optimizer/using/campaigns/get-started-with-campaigns#workflow)
