# Get Started with queries queries-gs

Last update: May 8, 2026
- Topics:
- [Data Management](#)

CREATED FOR:

- Beginner

Query Editor is an interactive tool provided by Adobe Experience Platform Query Service, which allows you to write, validate, and run queries for customer experience data within Adobe Journey Optimizer user interface.

Query Editor supports developing queries for analysis and data exploration, and allows you to run interactive queries for development purposes as well as non-interactive queries to populate [datasets](/en/docs/journey-optimizer/using/data-management/datasets/get-started-datasets).

Learn how to use the Query Editor in [this documentation](/en/docs/experience-platform/query/ui/user-guide#_blank).
