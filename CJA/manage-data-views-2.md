Select **Data Management** > **Data views** from the main menu bar in Customer Journey Analytics.

You can quickly search for a data view using the box.

## Filter data views

## Create a data view

To [create a new data view](/en/docs/analytics-platform/using/cja-dataviews/create-dataview), select **Create new data view**.

## Edit data views

If you want to [edit a data view](/en/docs/analytics-platform/using/cja-dataviews/create-dataview):

- Select next to the data view name.
- Select **Edit** from the context menu.

Alternatively, you can:

- Select the data view row.
- Select **Edit** from the blue action bar.

## Copy data views

If you want to copy a data view:

- Select next to the data view name.
- Select **Copy** from the context menu.

Alternatively, you can:

- Select one or more data view rows.
- Select **Copy** from the blue action bar.

The data view is copied and added to the list with **(Copy)** appended to the name.

## Delete data views

If you want to delete a data view:

- Select next to the data view name.
- Select **Delete** from the context menu.

Alternatively, you can:

- Select one or more data view rows.
- Select **Delete** from the blue action bar.

When you delete one or more data views, a **Delete data view** panel indicates which projects are affected.

- In ➊ **Confirmation**, the implications of the deletion of the data views are shown.
- Select **Delete** to delete the data views permanently. Select **Cancel** to cancel.

## Export data views to CSV

You can export a data view to a CSV file.

- Select next to the data view name.
- Select **Export to CSV** from the context menu.

Alternatively, you can:

- Select one or more data view rows.
- Select **Export to CSV** from the blue action bar.

Details of the selected data views are exported to a CSV file named Data views List (x).csv in your browser’s Downloads folder.

## Create project from data views

You can create a Workspace project directly from the Data views interface.

- Select next to the data view name.
- Select **Create project** from the context menu.

Alternatively, you can:

- Select a data view row.
- Select **Create project** from the blue action bar.

## Enable or disable data views for Data Insights Agent

You can enable or disable a data view for the [Data Insights Agent](/en/docs/analytics-platform/using/cja-overview/cja-b2c-overview/data-analysis-ai).

- Select next to the data view name.
- Select **Enable for Data Insights Agent** or **Disable for Data Insights Agent** from the context menu.

Alternatively, you can:

- Select one or more data view rows that are either disabled or enabled for the Data Insights Agent.
- Select **Enable for Data Insights Agent** or **Disable for Data Insights Agent** from the blue action bar.
