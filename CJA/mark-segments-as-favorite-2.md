# Mark segments as favorite

Last update: May 13, 2026
- Topics:
- [Filters](#)
- [Segments](#)

CREATED FOR:

- User

You can mark a segment as a favorite. To mark segments as favorite helps you to organize your segments. All users can favor segments.

To favor or unfavor a segment, in the [Segment manager](/en/docs/analytics-platform/using/cja-components/segments/seg-manage):

- Select to favor, or select to unfavor a segment.

You can sort your list of segments by favorites. Select **Other segments** from the **Segment** panel and select **Favorites**. See [Segment the list of segments](/en/docs/analytics-platform/using/cja-components/segments/seg-filter) for more information.
