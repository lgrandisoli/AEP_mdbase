# Tag calculated metrics

Last update: May 13, 2026
- Topics:
- [Calculated Metrics](#)

CREATED FOR:

- User
- Admin

In the [Calculated metrics manager](/en/docs/analytics-platform/using/cja-components/cja-calcmetrics/cm-workflow/cm-manager), you can use tags to organize calculated metrics. Administrators can tag all calculated metric. Non administroators can tags only the calculated metrics they create or have been shared with them.

To tag one or more calculated metrics:

- In the Calculated metrics manager , select one or more of the calculated metrics you want to tag.
- From the action bar, select Tag .
- In the Tag Calculated metrics dialog (optionally) use to search for and limit the list of tags. Based on the list of tags: select one or more existing tags from the list, or enter a new tag and press ENTER . Repeat to add more than one new tag.
- Select Save to save the tags for the calculated metrics. Select Cancel to cancel.

Once saved, the tags are listed in the Tag field for the selected calculated metric in the [Calculated metric builder](/en/docs/analytics-platform/using/cja-components/cja-calcmetrics/cm-workflow/cm-tagging).
